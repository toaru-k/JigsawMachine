# JigsawMachine.exe

JigsawMachine.exeは、.png, .jpeg, .bmp画像からジグソーパズルを生成し、それを解くパズルゲームです。

このゲームは、1.44MB GAME_DEV CONTEST に応募するために作られました。

## 遊び方

ゲーム画面右上に表示される３つのボタンは左からそれぞれ、アップロード、セーブ、ロードです。

![sample1.png](sample1.png)

### アップロード

新たにパズルを生成したいときは、アップロードです。

画像ロードボタンを押して、お好きな画像(.png, .jpeg, .bmp)を選択してください。
次に現れるダイアログで、難易度を選択できます。
すると、自動でピースが生成され、右側のインベントリに格納されます。

インベントリからプレイグラウンドにピースをドラッグ＆ドロップして、すべてのピースを結合させましょう。

画像が複雑なほど、ピースは細かく、パズルは複雑になります。

また、アップロードは File Explorer から画像ファイルをドラッグ＆ドロップすることでも行えます。

まずは、同梱の `sample1.png`, `sample2.jpg` で遊んでみましょう。

### セーブ/ロード

ゲームプレイ中の状態を、いつでもセーブできます。

セーブした状態は、ロードボタンからいつからでも復元できます。この間にゲームを終了しても大丈夫です。


## ゲームコンセプト

ゲームを1.44MBに収まるようにする中でもっとも難しいのは、コンテンツ量の確保です。とくに画像はデータサイズの肥大化の原因です。

そこで私は、どのコンピュータにも画像が保存されていることに目をつけました。気合を入れて作った料理、ゲームで面白かった瞬間、愛するペット、現代人はすべてを画像で保存します。それらからゲームコンテンツを生成できれば、コンテンツ量は事実上無限と言えるでしょう。

画像から生成するゲームコンテンツといえば、真っ先に思い浮かぶのはジグソーパズルでしょう。
シンプルながら、面白いゲームです。

しかし問題は、画像からどのようにピースを生成するかでした。
ただグリッド線にそって分割するのでは面白くありませんが、ピースを要素ごとに分解するのは複雑な処理が必要になります。

そこで、私はあえて画像の色の表現能力を下げることにしました。
RGBそれぞれに割り当てられるビット数を、4Bit に制限したのです。

これにより、フロッピーディスクが活躍した時代のような雰囲気が生まれるとともに、同じ色を結合するだけである程度の大きさのピースになります。
しかもこれは、同じ要素の一部であるという意味をもった分割であり、1.44MBに容易に収まる簡単なアルゴリズムで複雑なピースを生成できます。

JigsawMachine.exeは、これらのアイデアをもとに制作されました。
