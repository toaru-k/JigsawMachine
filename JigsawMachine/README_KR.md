# JigsawMachine.exe

JigsawMachine.exe는 .png, .jpeg, .bmp 이미지로부터 직소 퍼즐을 생성하고 이를 푸는 퍼즐 게임입니다.

이 게임은 1.44MB GAME_DEV CONTEST 출품을 위해 제작되었습니다.

## 플레이 방법

먼저 이미지를 로드해 봅시다. 게임 화면 우측 상단에 표시되는 3개의 버튼은 왼쪽부터 각각 업로드, 저장, 로드입니다.

![sample1.png](sample1.png)

### 업로드

새로운 퍼즐을 생성하고 싶을 때는 업로드를 사용합니다.

이미지 로드 버튼을 누르고 원하는 이미지(.png, .jpeg, .bmp)를 선택해 주세요.
다음으로 나타나는 대화상자에서 난이도를 선택할 수 있습니다.
그러면 자동으로 피스가 생성되어 오른쪽 인벤토리에 저장됩니다.

인벤토리에서 플레이그라운드로 피스를 드래그 앤 드롭하여 모든 피스를 결합해 봅시다.

이미지가 복잡할수록 피스는 잘게 쪼개지고 퍼즐은 복잡해집니다.

또한 업로드는 파일 탐색기(File Explorer)에서 이미지 파일을 직접 드래그 앤 드롭하여 수행할 수도 있습니다.

먼저 동봉된 `sample1.png`, `sample2.jpg`로 플레이해 봅시다.

### 저장 / 로드

게임 플레이 중의 상태를 언제든지 저장할 수 있습니다.

저장된 상태는 로드 버튼을 통해 언제든지 복원할 수 있습니다. 그 사이에 게임을 종료해도 괜찮습니다.

## 게임 콘셉트

게임을 1.44MB에 맞추는 과정에서 가장 어려운 점은 콘텐츠 양을 확보하는 것입니다. 특히 이미지는 데이터 크기를 비대하게 만드는 주요 원인입니다.

그래서 저는 모든 컴퓨터에 이미지가 저장되어 있다는 사실에 주목했습니다. 정성 들여 만든 요리, 게임에서 재미있었던 순간, 사랑하는 반려동물 등 현대인들은 모든 것을 이미지로 저장합니다. 이들로부터 게임 콘텐츠를 생성할 수 있다면 콘텐츠 양은 사실상 무한하다고 할 수 있을 것입니다.

이미지에서 생성하는 게임 콘텐츠라고 하면 가장 먼저 떠오르는 것은 직소 퍼즐일 것입니다.
간단하면서도 재미있는 게임입니다.

하지만 문제는 이미지에서 '어떻게' 피스를 생성할 것인가였습니다.
단순히 격자선을 따라 분할하는 것은 재미가 없지만, 시각적 요소별로 피스를 분해하려면 복잡한 처리 과정이 필요합니다.

그래서 저는 의도적으로 이미지의 색상 표현 능력을 낮추기로 했습니다.
RGB 각각에 할당되는 비트 수를 4Bit로 제한한 것입니다.

이로 인해 플로피 디스크가 활약했던 시대와 같은 분위기가 연출됨과 동시에, 비슷한 색상을 결합하는 것만으로도 어느 정도 크기의 피스가 만들어집니다. 게다가 이는 같은 요소의 일부라는 의미를 가진 분할 방식이며, 1.44MB에 쉽게 들어가는 간단한 알고리즘으로 복잡한 피스를 생성할 수 있게 해줍니다.

JigsawMachine.exe는 이러한 아이디어를 바탕으로 제작되었습니다.
